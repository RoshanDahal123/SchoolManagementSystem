# Antigravity Rules

## Output Constraints
- Be concise. Give direct answers first.
- Do not explain obvious code, basic logic, syntax, or standard framework behaviors.
- Write code updates as minimal diffs, not full-file rewrites.
- Omit conversational filler, greetings, and lengthy summaries.

## Coding Style
- Follow existing project patterns closely.
- Fix compilation issues without adding unnecessary abstractions.
